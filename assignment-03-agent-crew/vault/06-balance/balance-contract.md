# Core Balance Contract — Echoes (GDD V2)

## Quantitative Balance Assertions (Adversarial QA Crew Mandate)

1. **Clearability Assertion:** Overall clearability MUST be 100% across all competent bot profiles (zero unhandled softlocks or impassable geometry).
2. **Win-Rate Parity:** Hunter vs Titan first-clear win rates MUST sit within a **15–35% per-attempt band** and remain within **±10 percentage points** of each other.
3. **Cause-of-Death Asymmetry:** Per-class cause of death MUST differ by **≥20 percentage points** (e.g., Titan deaths dominated by Knight melee attacks; Hunter deaths dominated by Witch predictive volleys).
4. **Run Duration Delta:** Average run completion time between Segment B branches MUST remain within **±20%**.
