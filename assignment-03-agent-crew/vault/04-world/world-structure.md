# World Structure & Route Topology — Echoes (GDD V2)

## World Flow Sequence
Start → Tutorial → Shared Segment A → Junction → Class-Exclusive Segment B Branches → Convergence → La Costurera Boss Room → Run Complete Screen.

## Route Description
1. **Tutorial (~2 min):** Teaches verbs in a safe environment. Kit is fully open.
2. **Shared Segment A (~5 min):** 3–6 rooms. Showcase of combat texture and optional side pockets.
3. **Junction Beat:** Gate corresponding to active class's tool opens automatically. The opposite class's gate stays visibly sealed (sells the 2nd run).
4. **Segment B Branches (~5 min):** Class-exclusive routes (Hunter Grapple route vs Titan Charge Bash route).
5. **Convergence (~1 min):** Both branches converge at a checkpoint prior to boss door (player sees exit of opposite branch).
6. **Boss Chamber:** La Costurera fight.
