# Class asymmetry — the contract

The law, stripped to what applies here. (The original states it in terms of
rooms and traversal; the principle is what carries.)

## The law

**Asymmetry budgets difficulty, never possibility.** Both classes can reach
anywhere the game asks them to reach. What differs is the shape of the
problem, never whether it is solvable.

**Exclusivity comes from placement, not from power.** Neither class is
stronger; neither has a bigger number. The difference is *where things sit*
relative to what each class is good at — in this game, the geometry of the
loom (`../loom-grid.md`).

**A class is not a costume.** It is a starting relic, a grid shape, and an
ultimate. Those three together must change how a run is played, or the
choice is decoration.

## What this forbids

- A relic, buff or wave that one class cannot answer at all.
- Making one class simply better at the same plan; the plans must differ.
- Balancing by giving a class more of something — more cells, more damage,
  more gold. Same budget, different shape.

## How it is proven

Not by argument. The simulator measures median depth per class over seeded
runs, and the two must land within the parity band
(`../wave-contract.md`).
