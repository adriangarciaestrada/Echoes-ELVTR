# Terminology & IP guard

## The mandate

The world must feel Destiny-adjacent and ship **100% legally clean in both
English and Spanish**. Working Destiny terms used while drafting are
PROHIBITED from all shipped text, UI strings, lore, and asset metadata.

## Banned placeholder → required term

| Banned | Required | Meaning here |
|---|---|---|
| Traveler / Light | **Architects / Weave** | the ancient cosmic origin and its energy |
| Ghost | **Beacon** | the Architect anchor the player defends |
| Hive / Vex / Fallen / Scorn | **Remnants / Facets** | the antagonist forms |
| Engram | **Architect Fragment / Data Node** | a collectible or data object |
| Guardians | **Weavers** | the player class lore skin |

Rows for characters that do not appear in this game were removed; if one is
ever introduced, fork the row from the original note rather than inventing a
new mapping.

## The ban is on the capital, not the word

Matched **case-sensitively**. `Light` is the Destiny placeholder and is
refused; `light` is an ordinary noun and passes — a rule that banned the
lower-case word would stop the game describing its own lighting.

## Banned region references

The setting is a what-if Golden Age that prospered in a real place, and it
is **recognised, never announced**. The country is never named in shipped
text in either language, and its loaded iconography ships only from an
approved-hint allowlist which is **empty by default**. The place is carried
by geology, light, vegetation, Spanish signage fragments and plausible
toponymy instead.

| Banned | Treatment |
|---|---|
| Mexico / México / Mexican / mexicano / mexicana | never named |
| Aztec / azteca / Mexica / mexica | off-allowlist iconography |
| Mayan / maya | off-allowlist iconography |
| Nahuatl / náhuatl | off-allowlist iconography |
| Quetzalcoatl / feathered serpent / serpiente emplumada | off-allowlist iconography |
| pyramid / pirámide | off-allowlist iconography `[TUNE]` |

A legitimate use is resolved by adding the specific hint to the allowlist,
never by weakening a row.

## Both languages are origin

Every string is authored in English and Spanish, not translated. Spanish
runs longer and therefore decides whether a string fits its widget
(`../ui-and-strings.md` owns the caps).
